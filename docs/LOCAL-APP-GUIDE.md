# راهنمای استفاده از کلاینت‌های محلی و اپلیکیشن همراه (`docs/LOCAL-APP-GUIDE.md`)

## ۱. اپلیکیشن اندروید (Android Companion App)
- اپلیکیشن اندروید در پوشه `app/` مستقر است و با زبان Kotlin و Jetpack Compose طراحی شده است.
- کاربر می‌تواند فایل‌های JSX یا پروژه‌های ری‌اکت را از حافظه گوشی یا درایو انتخاب کرده و با زدن دکمه تبدیل، پکیج وردپرس آماده را در پوشه Downloads گوشی دریافت کند.
- امکان ساخت و تست مستقیم از طریق Android Studio یا محیط ابری با دستور Gradle.

## ۲. استفاده از ابزار خط فرمان (CLI)
- در هر محیط ترمینال لینوکس، مک یا ویندوز:
  ```bash
  npx rtw-convert ./my-component.tsx --type block-theme --name "My FSE Theme"
  ```
- پشتیبانی از ورودی‌های پوشه و فایل‌های فشرده `.zip`.
