# 🚀 راهنمای شروع سریع (Quick Start Guide - فارسی)

به سامانه جامع **RTW Converter (Ra-Ai2WP-Engine)** خوش آمدید. این پلتفرم پیشرفته، کامپوننت‌های مدرن ری‌اکت (React, Next.js, JSX/TSX) و خروجی‌های هوش مصنوعی (مانند v0, Bolt, Lovable) را با رعایت دقیق استانداردهای **WPCS 3.4.1** به قالب‌ها و پلاگین‌های آماده و استاندارد وردپرس تبدیل می‌کند.

---

## 🧭 انتخاب روش کار بر اساس نیاز شما

| سناریوی شما | روش پیشنهادی | زمان تخمینی |
| :--- | :--- | :--- |
| **می‌خواهم مستقیماً از داخل پیشخوان وردپرس کار کنم** | افزونه وردپرس `wp-github-bridge` | کمتر از ۱ دقیقه |
| **یک پوشه یا فایل زیپ دانلود شده دارم و گیت نمی‌خواهم** | وب‌سایت گیت‌هاب (Workflow Dispatch) | ۱ تا ۲ دقیقه |
| **توسعه‌دهنده فرانت‌اند هستم و در ترمینال کد می‌زنم** | ابزار خط فرمان `npx rtw-convert` | چند ثانیه |
| **روی گوشی همراه یا تبلت در حال بررسی پروژه هستم** | اپلیکیشن همراه اندروید (Android Studio Client) | آنی |

---

## ۱. راهنمای استفاده از افزونه وردپرس (`wp-github-bridge`)

1. پوشه `wp-github-bridge` را در مسیر `wp-content/plugins/` هاست خود قرار دهید یا فایل زیپ آن را از بخش Releases دانلود و در بخش «افزونه‌ها > افزودن» بارگذاری نمایید.
2. افزونه **RTW GitHub Bridge** را فعال کنید.
3. در منوی مدیریت وردپرس، روی گزینه جدید **RTW Bridge** کلیک کنید.
4. نام مخزن (پیش‌فرض: `Aqamirrazavi/Ra-Ai2WP-Engine`) و توکن گیت‌هاب (PAT) خود را در کادر تنظیمات وارد کنید.
5. اکنون کد React خود یا لینک فایل فشرده را قرار داده و فرمت دلخواه (قالب بلوکی FSE، قالب کلاسیک، پلاگین یا بلاک گوتنبرگ) را انتخاب کنید و دکمه **«ارسال رویداد به GitHub Actions»** را بزنید.
6. سرورهای ابری گیت‌هاب پکیج وردپرس شما را تولید کرده و لینک دانلود مستقیم آن را آماده می‌سازند.
7. **قابلیت Auto-Update:** به لطف هدر `Update URI`، هر زمان نسخه جدیدی از هسته در گیت‌هاب منتشر شود، پیشخوان وردپرس شما به صورت خودکار متوجه شده و دکمه به‌روزرسانی نمایان می‌شود!

---

## ۲. استفاده از وب‌سایت گیت‌هاب (بدون نیاز به ابزار یا سرور محلی)

اگر کدهای خود را به صورت یک فایل فشرده (`.zip`, `.tar.gz`) دانلود کرده‌اید:
1. به تب **Actions** در مخزن گیت‌هاب بروید.
2. از منوی سمت چپ، ورک‌فلو **RTW Universal WordPress Transpiler** را انتخاب کنید.
3. روی دکمه **Run workflow** کلیک کنید.
4. در فیلد `Archive URL`، لینک مستقیم دانلود فایل فشرده کدهای ری‌اکت را وارد کنید (یا اگر فایل‌ها را در مخزن پوش کرده‌اید، مسیر پوشه مثل `src` را بدهید).
5. نوع خروجی و پشتیبانی از راست‌چین (RTL) را تعیین کرده و اجرا کنید.
6. پس از اتمام پردازش، در همان صفحه وارد بخش **Artifacts** شوید و فایل زیپ نهایی وردپرس را مستقیماً دانلود کنید!

---

## ۳. استفاده از ابزار خط فرمان (CLI)

برای توسعه‌دهندگانی که روی پروژه در محیط لوکال کار می‌کنند:

```bash
# تبدیل مستقیم یک کامپوننت به تم بلوکی FSE:
npx rtw-convert ./src/App.tsx --type block-theme --name "My Modern Theme"

# تبدیل یک فایل فشرده زیپ با خروجی پکیج آماده:
npx rtw-convert ./downloaded-project.zip --type block-theme --zip ./dist/my-theme.zip

# تولید افزونه وردپرس با مسیرهای REST API:
npx rtw-convert ./src/Dashboard.tsx --type plugin --name "Dashboard Bridge"
```

## ۴. استانداردهای خروجی وردپرس

تمامی خروجی‌های ساخته‌شده با این سیستم:
- از استانداردهای **WPCS 3.4.1** پیروی می‌کنند (فراردهی با `esc_html`، `esc_attr`، `esc_url`).
- از نانس‌های وردپرس (`wp_verify_nonce`) برای امنیت فرم‌ها استفاده می‌کنند.
- به صورت کامل پیشوندگذاری ایمن (`rtw_`) شده‌اند تا با سایر پلاگین‌ها تداخل نداشته باشند.
- دارای فایل استایل اختصاصی راست‌چین (`rtl.css`) برای زبان فارسی و عربی هستند.
