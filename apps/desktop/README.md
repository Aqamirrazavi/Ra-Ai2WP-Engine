# RTW Desktop Client (`apps/desktop`)

Desktop companion client for Ra-Ai2WP-Engine, supporting Windows, macOS, and Linux.

## Features
- **Offline React-to-WordPress Transpilation**: Direct local parsing of JSX/TSX components.
- **WPCS 3.4.1 Code Sniffing**: Integrated security linter for PHP code output.
- **GitHub Bridge Integration**: One-click dispatch to repository workflows.
- **System Tray & Hotkeys**: Instant access for front-end developers.
